# Post-Purchase Feedback Example

Use this reference only when the user asks for a post-purchase, feedback, reply, review, or photo-response email and needs a concrete structure model.

For this scenario, treat the campaign as engagement-first rather than sales-first. Favor trust, appreciation, easy response paths, and a warm human tone over merchandising or hard-sell CTAs.

When useful, read `example-results.json` as the canonical bundled example for the natural-food-colors post-purchase feedback prompt. Treat it as a style and structure reference, not copy to reuse verbatim.

Prefer:

- a clear hero or intro focused on curiosity, gratitude, or feedback
- short explanatory copy that makes the ask feel easy
- a highlighted question or prompt block
- reply-, review-, or photo-sharing CTAs when supported by real destinations
- a warm closing or signature when a real signer is known

Avoid product grids, invented imagery, guessed contact addresses, or discount-focused framing unless the user specifically asks for them.

If optional imagery is unavailable, leave image fields blank when allowed. If a reply address, review flow, or upload destination is required but unknown, ask the user or choose a simpler section.
